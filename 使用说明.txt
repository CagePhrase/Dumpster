Dumpster 垃圾桶桌宠 — 使用说明
================================

一个住在你桌面上的垃圾桶。你往它里面扔话，它接住，然后回你一句。


一、下载哪个文件
--------------------------------
推荐：Dumpster_0.0.1_x64-setup.exe   （约 1.6 MB，一路点下一步即可）
备选：Dumpster_0.0.1_x64_en-US.msi   （约 2.4 MB，适合公司电脑批量安装）

两个装的是同一个程序，选一个就行。


二、系统要求
--------------------------------
· Windows 10 / 11，64 位
· 需要 Microsoft Edge WebView2 运行时
  （Win11 自带；Win10 若没装过，安装程序会提示，或从微软官网免费下载）


三、安装
--------------------------------
1. 双击 Dumpster_0.0.1_x64-setup.exe
2. 如果 Windows 弹出"已保护你的电脑"，点"更多信息" → "仍要运行"
   （这是因为没有购买代码签名证书，属于正常现象）
3. 按提示完成安装，桌面上会出现一只垃圾桶


四、第一次使用
--------------------------------
装好后任务栏右下角会出现一个小图标（可能被折叠进 ^ 里）。
右键它，菜单里有：

  打开控制台        —— 查看投喂记录、它写的日记、修改设置
  和它说一句话      —— 立刻打开输入框
  查看记录与日记    —— 直接跳到记录界面
  把桌宠叫回来      —— 它跑出屏幕外时用这个
  退出 Dumpster

基本操作：
· 左键点它        —— 打开输入框，扔一句话进去
· 按住拖动        —— 把它挪到别处
· 输入框里 Enter  —— 提交，Shift+Enter 换行，Esc 关闭
· 长按它          —— 退出程序（和托盘菜单里的"退出"一样）


五、配置 AI（可选，但强烈建议）
--------------------------------
不配 AI 也能用：它会用内置话术和本地模板回你，日记也能写，
只是句子是固定的那几十条。

想让它真正会接话、会写日记，需要你自己的 API Key：

1. 到 https://platform.deepseek.com 注册，创建一个 API Key
   （形如 sk-xxxxxxxx）
2. 右键托盘图标 → 打开控制台 → 左侧"设置" → 找到 AI 那一栏
3. 把 Key 粘贴进去 → 点"保存"
4. 点"测试连接"确认能通

关于费用：调用是按量计费的，很便宜。一次对话通常不到一分钱。
Key 只保存在你自己电脑上，不会上传到任何地方。

【重要】程序本身不包含任何 API Key，你必须自己配置。
        别人给你的 Key 不要用，也不要把自己的 Key 发给别人。


六、授权（只影响"AI 学习"这一项）
--------------------------------
免费版：AI 回复、AI 日记、全部功能都能用。

收费版：解锁"AI 学习"——它会分析你喂过的内容，
        记住你反复提到什么、处在什么状态，然后调整跟你说话的方式。

没授权时：它照样有性格、照样会损你，只是不了解你。

激活方式：设置 → 授权 → 粘贴授权码 → 激活


七、你的数据存在哪
--------------------------------
投喂记录、日记、设置：
  %APPDATA%\com.dumpster.app\dumpster-state.json

运行日志（出问题时发给开发者）：
  %LOCALAPPDATA%\com.dumpster.app\dumpster.log

全部只存在本机。卸载程序不会自动删除这些，需要手动清理。


八、常见问题
--------------------------------
Q: 装完没看到垃圾桶？
A: 可能在屏幕边缘外。右键托盘图标 → "把桌宠叫回来"。

Q: 任务栏找不到图标？
A: Win11 会把它折叠进 ^ 里，点 ^ 展开，或拖到任务栏上固定。

Q: 它一直不说话？
A: 检查设置里的"它多久说一句话"，最低 3 分钟。

Q: 配置了 Key 但回复还是很简单？
A: 点"测试连接"看是否报错。也检查 Key 是否还有余额。

Q: 想彻底卸载干净？
A: 卸载程序后，手动删除 %APPDATA%\com.dumpster.app 和
   %LOCALAPPDATA%\com.dumpster.app 两个文件夹。
